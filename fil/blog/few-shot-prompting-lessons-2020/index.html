Ang itinuturo pa rin ng few-shot prompting noong 2020 sa mga content team

5 Okt 2026 · 6 minutong basa · Editorial team ng GPT3 Marketing · FAQ

Itinuro ng few-shot prompting sa mga unang gumamit ng GPT-3 na mas natututunan ng model ang isang voice mula sa mga halimbawa kaysa sa mga pang-uri. Sa 2026, kasama ang matatas na model na sumusunod sa instruction, totoo pa rin ang aral: ang mga team na nagpapakain sa model ng piniling halimbawang nakabatay sa audience ay nakakakuha ng natatanging content, habang ang mga team na naglalarawan lang ng kanilang tono ay nakakakuha ng parehong karaniwang copy gaya ng iba.

Ano talaga ang hitsura ng pagsusulat gamit ang GPT-3 noong 2020?

Noong Mayo 2020, inilathala ng OpenAI ang "Language Models are Few-Shot Learners", ang paper na naglalarawan sa GPT-3, isang model na may 175 bilyong parameter. Ang pangunahing claim nito ay kayang matuto ng sapat na laking model ng isang gawain mula sa iilang halimbawang inilagay sa prompt, nang walang retraining. Noong Hunyo 2020, nagbukas ang API bilang private beta, at tag-init na iyon nagsimulang gumamit nito ang GPT3 Marketing.

Walang chat window. Sumusulat kayo ng prompt na mukhang simula ng isang dokumento: tatlo o apat na halimbawang product description, bawat isa ay may maikling input at tapos na output, saka isang bagong input at isang bakanteng espasyo. Ipinagpapatuloy ng model ang pattern. Kung matabang ang inyong mga halimbawa, matabang ang output. Kung mas mahaba nang malaki ang isang halimbawa kaysa sa iba, humahaba ang mga output. Bawat kakaibang katangian ng mga halimbawa ay lumalabas, at pinalalaki pa, sa resulta.

Mabigat itong paraan ng pagtatrabaho, at pinilit nito ang isang disiplinang nawala sa karamihan ng team nang dumating ang mga chat interface noong Nobyembre 2022.

Bakit mas mahusay ang mga halimbawa kaysa sa mga pang-uri?

Hilingin sa isang modernong model na sumulat sa voice na "warm, confident and witty" at makakakuha kayo ng isang bagay na warm, confident at witty sa paraang ginagawa ng libu-libong ibang brand. Nasa bawat brand book ang mga pang-uring iyon. Nakita na ng model ang mga ito na nakakabit sa napakalawak na hanay ng text at ibinabalik nito ang gitna ng hanay na iyon.

May dalang impormasyon ang mga halimbawa na hindi kaya ng mga pang-uri: haba ng pangungusap, kung saan tumatama ang biro, aling mga salita ang hindi ninyo kailanman ginagamit, paano ninyo hinahawakan ang reklamo, kung "kami" o "ang team" ang isinusulat ninyo. Ang mahusay na halimbawa ay isang siksik na voice guide. Kaya binuo ang aming mga brand voice system sa paligid ng mga halimbawa sa halip na mga paglalarawan ng tono.

Inilalarawan ng mga instruction ang gusto ninyo. Pinatutunayan ito ng mga halimbawa. Nagtitiwala ang mga model sa patunay.

Aling mga gawi noong 2020 ang sulit panatilihin?

1. Piliin ang mga halimbawa na parang portfolio

Noong 2020, may gastos sa token at pera ang bawat halimbawa, kaya maingat namin silang pinili. Ngayon, mura na ang context at idinidikit ng mga team ang buong archive. Hindi mas mahusay ang mas marami. Piliin ang mga piyesang pinakamahusay na kumakatawan sa voice sa pinakamalakas at pinakatiyak nitong anyo, at pag-ibahin ang mga format para matutunan ng model ang voice, hindi ang iisang template.

2. Gawing tahasan ang pattern

Pinakamahusay gumana ang mga few-shot prompt kapag pare-pareho ang istruktura: may label na input, may label na output, malinaw na separator. Ganoon din ang prinsipyo sa mga modernong prompt. Ipakita sa model kung ano ang pumapasok at ano ang lumalabas, para malaman nito kung aling bahagi ng halimbawa ang nakapirming voice at alin ang nagbabagong content.

3. Basahin ang bawat output bilang editor

Walang naglathala ng hilaw na text ng GPT-3. Lumilihis ito, umuulit, at paminsan-minsang nag-iimbento ng mga fact nang buong kumpiyansa. Mas mahusay nang malaki ang mga modernong model, pero ang gawi ng editor pa rin ang pinakamurang quality control na mayroon. Tinatalakay namin ito nang mas detalyado sa bakit kailangan pa rin ng mabigat na pag-edit ang mga AI draft.

4. Ituring na asset ang prompt

Ilang oras ang inaabot para ayusin ang isang mahusay na few-shot prompt, kaya vine-version namin ito, idinodokumento at muling ginagamit. Nag-evolve iyon tungo sa prompt library practice na pinapatakbo namin para sa mga kliyente ngayon.

Saan dapat magmula ang mga halimbawa?

Dito naiiba ang 2026 sa 2020. Noon, nagmumula ang mga halimbawa sa sariling archive ng brand. Ang problema, sinasalamin ng mga archive ang gustong sabihin ng brand, hindi kinakailangang ang tinugunan ng audience. Kung ang pinakamahusay ninyong halimbawa ay ang sarili ninyong paboritong post, ang gusto ninyo ang matututunan ng model, hindi ang gusto ng inyong audience.

Ibinabatay na namin ngayon sa audience evidence ang pagpili ng mga halimbawa. Gamit ang mga strategy tool ng SOMIN, dahil ang SOMIN ay isang AI audience-research platform, tinitingnan namin ang mga usapan sa paligid ng isang kategorya: ang mga pariralang talagang ginagamit ng mga tao, ang mga tensyong ipinapahayag nila, ang mga tonong nakakakuha ng reply sa halip na scroll. Saka kami pumipili o sumusulat ng mga halimbawang tumutugon sa mga detalyeng iyon. Sabay na minamana ng model ang voice ng brand at ang bokabularyo ng audience.

Kapaki-pakinabang na karagdagang babasahin ang Fujifilm case study tungkol sa kung paano hinuhubog ng audience insight ang sinasabi ng isang brand, bago pa may humawak sa mga salita.

Isang halimbawa: isang product line, dalawang prompt

Isipin ang isang skincare brand na sumusulat ng mga description para sa isang bagong serum.

  • Sinasabi ng Prompt A: "Sumulat ng warm at expert na product description para sa aming bagong vitamin C serum. Friendly at science-led ang aming tono."
  • Kasama sa Prompt B ang tatlong dating description na mahusay ang performance, bawat isa ay ipinares sa brief nito, dagdag ang maikling tala ng mga pariralang ginagamit ng audience tungkol sa problema (halimbawa, kung paano nila inilalarawan ang dullness o sensitivity sa sarili nilang salita), saka ang bagong brief.

Ibinabalik ng Prompt A ang mahusay na copy na puwedeng pag-aari ng kahit anong brand sa shelf. Ibinabalik ng Prompt B ang copy na may ritmo ng brand at wika ng audience. Hindi kalidad ng model ang pagkakaiba. Kalidad ng input.

Checklist: few-shot prompt para sa brand content

  • Dalawa hanggang limang halimbawa, iba-iba ang format at haba
  • Bawat halimbawa ay ipinares sa brief na lumikha nito
  • Pare-parehong label at separator
  • Maikling listahan ng mga parirala at tensyon ng audience, mula sa totoong usapan
  • Maikling listahan ng mga bagay na hindi kailanman sinasabi ng brand
  • Isang pinangalanang human reviewer para sa output

Mga kahulugan

  • Zero-shot: paghiling sa model na gawin ang isang gawain gamit lang ang mga instruction.
  • Few-shot: pagsasama ng kaunting halimbawa sa prompt.
  • In-context learning: ang pag-angkop ng model sa mga pattern sa prompt nang hindi binabago ang mga weight nito.

Bakit mahalaga ito ngayon

Kapag may access ang lahat sa parehong mga model, lumilipat ang kalamangan sa mga input. Isinilang ang disiplina ng few-shot mula sa kakapusan noong 2020; sa 2026, paraan ito para makatakas sa pagkakapare-pareho. Kung gusto ninyong makita kung paano nagiging praktikal na desisyon sa marketing ang audience signal sa ibang lugar, dine-decode ng mga lingguhang episode ng Marketing Mondays ang isang totoong signal sa bawat pagkakataon, isang magandang gawing ipares sa mas matalas na prompt.

Bihirang ang mga brand na natatangi ang tunog gamit ang AI ay ang may pinakamatalinong instruction. Sila ang may pinakamahusay na halimbawa, na pinili nang isinasaalang-alang ang kanilang audience.

Mga madalas itanong

Ano ang few-shot prompting?

Ang few-shot prompting ay ang pagbibigay sa isang language model ng kaunting halimbawa ng isang gawain sa loob ng prompt, para mahinuha nito ang pattern at ipagpatuloy ito. Pinasikat ng GPT-3 paper noong 2020 ang termino.

Kapaki-pakinabang pa rin ba ang few-shot prompting sa mga modernong model?

Oo. Sinusunod ng mga instruction-tuned model ang mga simpleng request, pero ang mga halimbawa pa rin ang pinakaeksaktong paraan para ilipat ang isang partikular na voice, istruktura o antas ng detalye. Naglalarawan ang mga instruction; nagpapakita ang mga halimbawa.

Ilang halimbawa ang dapat isama sa isang content prompt?

Karaniwang dalawa hanggang limang matibay at iba-ibang halimbawa. Kapag masyadong kaunti, sobrang kinokopya ng model ang isa; kapag masyadong marami, natatabunan ninyo ang brief. Mas mahalaga ang kalidad at pagkakaiba-iba kaysa sa bilang.
